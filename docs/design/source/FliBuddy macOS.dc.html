macOS

One main window and a Settings window. USB or Bluetooth to the Flipper. Built for a keyboard on the bench: the weight field takes focus by itself, ⌘S saves. Use the Tweaks panel to switch between the macOS 27 and macOS 14 rendering.

Main windowLive prototype; both windows show the same session. Type in the focused field, Tab to Net/Gross, Return or ⌘S to save. Click a saved row to weigh it again.
WindowGroup("FliBuddy") {
  FeedView()
    List(selection: $focusedRow) {
      ForEach(feed) { FeedRow($0) }
    }.listStyle(.inset)
    .toolbar {
      Button("Clear", systemImage: "trash")
        .keyboardShortcut(.delete)
      SettingsLink { Label("Settings",
        systemImage: "gearshape") }
    }
    .safeAreaInset(edge: .bottom) {
      StatusBar()   // Flipper · Bambuddy
    }
    .overlay { ContentUnavailableView }
    .sheet(item: $sheet) {
      NewSpoolForm / LinkPicker }
    .confirmationDialog("Clear the feed?")
}

Settings window Grouped Form, four sections, opened with ⌘, or the toolbar. Light shows USB and a passing test; dark shows Bluetooth and a failed test. Changes apply as you make them, like any macOS Settings window; there is no Save button.
