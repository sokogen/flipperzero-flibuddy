FliBuddy

A bench tool for weighing filament spools. Hold a tag to the Flipper, read the scale, save to Bambuddy, next spool. Native SwiftUI on macOS 14+, iOS, iPadOS and watchOS 26+, drawn in the 27 idiom.

01

Stance

One number per row
The weight is the critical path. The newest row that needs it takes focus with the suggestion pre-filled and selected; typing replaces it. A correct suggestion costs one tap.
Readable at a metre
The weight is the only custom-sized type: 34 pt on iPhone, 22 pt on Mac, 50 pt on Watch, all with monospaced digits so numbers don't jitter while typing. Everything else is a system text style and follows Dynamic Type.
Status is a word first
Every state is a short sentence-case phrase plus an SF Symbol. Colour reinforces it and never carries meaning on its own. The swatch always sits next to the title and colour name.
Stock parts only
List, Form, NavigationSplitView, TabView, sheets, ContentUnavailableView. Liquid Glass appears only where the system puts it. On macOS 14 the same code renders the classic look with no special-casing.
Assumptions to confirm
  1. The suggestion is gross (remaining + core). Switching Net/Gross converts an untouched suggestion and keeps a number you typed.
  2. After New the row stays open for a first weight: "Created in Bambuddy" with the field pre-filled to label + core.
  3. Saved rows reopen on tap or click for a re-weigh. Last save wins; the status says who saved.
  4. The watch creates Bambu Lab tags in one tap but cannot fill the form; for other tags it says "Create it on iPhone or Mac".
  5. iPhone and iPad settings apply on change. macOS keeps the explicit Save section from the brief.
  6. "Link to existing" warns when the chosen spool already carries a different tag and offers to move the link.
  7. Watch is dark only, as watchOS is. Every other surface is shown light and dark.
  8. In these mock-ups an open icon set stands in for SF Symbols. Hover any icon for the real symbol name; the full list is in 02.

Anatomy
  1. Swatch, 28 pt Circle() from tag RGBA. No colour: dashed .tertiary outline. Hidden from VoiceOver; the colour name is read instead.
  2. Title: material + subtype, .headline. Blank tags read "NTAG 7-byte UID 04A2…".
  3. Colour name from the inventory. Absent when unknown; never the hex.
  4. Remaining: "590 g left of 1000", or "label 1000 g" for unknown tags with prefill.
  5. Status: symbol + phrase, .secondary; text turns .red only for errors.
  6. Weight entry: field → Net/Gross → readout → Save. Present for Enter weight, Created, Error and Saving (disabled).
  7. UID, .caption.monospaced(), .tertiary, trailing.
VoiceOver reads the header as one element: "PLA Basic, Bambu Green, 590 grams left of 1000, Enter weight". The field label is "Gross weight, grams".
