iPad

Landscape on a bench stand, usually with a keyboard. NavigationSplitView: the sidebar carries both connection states, Feed, Spools (the read-only inventory), Settings and Clear; the detail is the feed as compact tiles, at most three to a row: three on a 13" iPad, two on an 11". Portrait keeps the tiles and swaps the sidebar for a top tab bar. A narrow Split View or Stage Manager window (compact width) gets the iPhone layout.

NavigationSplitView {
  List(selection: $pane) {
    Section("Connections") {
      FlipperStatusRow()
      BambuddyStatusRow() }
    NavigationLink(value: .feed) {
      Label("Feed", systemImage:
        "list.bullet") }.badge(feed.count)
    NavigationLink(value: .spools) {
      Label("Spools", systemImage:
        "shippingbox") }.badge(active)
    NavigationLink(value: .settings) {
      Label("Settings", systemImage:
        "gearshape") }
  }
  .safeAreaInset(edge: .bottom) {
    Button("Clear feed",
      systemImage: "trash",
      role: .destructive)
      .keyboardShortcut(.delete) }
} detail: {
  ScrollView {
    LazyVGrid(columns: [GridItem(
      .adaptive(minimum: 300))]) {
      ForEach(feed) { FeedTile($0) } } }
  // at most 3 columns: 3 on 13", 2 on 11"
}

// TabView, top tab bar, banner,

// Manager): the iPhone TabView, cards
// Spools: tiles as the feed's (List
// only at compact width), .searchable,
// detail in .inspector (320 pt) beside
